# Sheljin S.A. — Static Portfolio

A responsive portfolio made with plain HTML, CSS, and JavaScript. No framework or build step is required.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, responsive styling, and sage/green/cream palette
- `script.js` — mobile navigation, current year, and reveal-on-scroll animations

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
Upload these files to any static host such as GitHub Pages, Netlify, or Cloudflare Pages. No backend is required.

## Customize
- Update links, project descriptions, and contact details in `index.html`.
- Change colors in the `:root` variables at the top of `styles.css`.
- The reference bird image is used only as a color-palette reference; it is not displayed in the portfolio.
- Google Fonts are loaded online. System fallbacks are included.
